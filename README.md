# Chinzilla Production Suite – Beta

**English** · [Deutsch](#deutsch)

Free beta of the Chinzilla Production Suite for Windows – rundown & show control, crew & call sheet,
PTZ cameras, floorplan, signal flow, teleprompter, countdown and more.

- **Download:** open the [latest release](https://github.com/ChinzillaFilms/cps-releases/releases/latest) and
  run `ProductionSuite-<version>-win-x64.exe`. Windows SmartScreen may warn on first install
  (“More info” → “Run anyway”) because the installer is not code-signed yet.
- **Updates** arrive automatically inside the app and are installed when you quit.
- **Beta:** under development, may contain bugs. Always keep an independent fallback for live use.
- By installing you agree to the terms of use shown in the app (*Settings → About / Legal*).
